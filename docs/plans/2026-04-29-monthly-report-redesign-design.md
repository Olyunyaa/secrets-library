# Дизайн: Переработка ежемесячного отчёта участников

**Дата:** 2026-04-29  
**Статус:** утверждён  
**Затрагивает:** `generate_monthly_report.py`

---

## Цель

Сделать ежемесячный отчёт операционным инструментом — чтобы сразу было видно, кто требует действия и чьего именно. Устранить 16 непривязанных Stripe Paid через расширение цепочки матчинга.

---

## Источники данных (без изменений)

- **Stripe** — единственный источник правды по оплатам (Paid / Failed / Refunded)
- **Telegram** — Канал (`-1003642141867`), Чат (`-1003403267547`), Практика (`-1002195167889`)
- **Salebot** — список Вовы (`list=1992711`)

Новые вкладки используются **только для матчинга** (email ↔ TG ник), не для определения членства.

---

## Расширенная цепочка матчинга (Stripe email → TG ник)

Первое совпадение побеждает:

1. `known_matches.json` — ручная таблица, самый надёжный источник
2. **Антихрупкость 2026** (вкладка в Google Sheet) — имя/фамилия + почта + ник, без шапки
3. **Резиденты** (вкладка в Google Sheet) — колонки Имя, Почта, Телеграм ник (остальные колонки игнорировать)
4. **Предыдущий Свод** (вкладка в Google Sheet) — переиспользуем уже сматченные пары email ↔ ник
5. Username == local part email (без точек/подчёркиваний, точное)
6. Username подстрока email local part (≥6 символов, точное)
7. Токен из email в имени/нике (≥7 символов, нечёткий → ⚠️ метка)

Шаги 2–4 — двунаправленные: email→ник и ник→email.

## Группировка (action-oriented, сверху вниз по приоритету)

### 🔴 Убрать из клуба
**Критерий:** нет оплаты в Stripe + в любом из трёх мест (канал / чат / практика)  
**Действие:** кандидат на удаление из всех групп  
**Исключение:** активная договорённость в `tanya_agreements.json`

Внутри группы два подвида:

| Подвид | Критерий | Пометка в колонке "Действие" |
|--------|----------|------------------------------|
| Нет оплаты | Stripe-записи нет вообще | "Удалить — нет оплаты" |
| Failed платёж | Stripe есть, статус FAILED | "Удалить — платёж не прошёл" |

> Failed — человек пытался оплатить, но не получилось. Таня может написать ему до удаления.

---

### 🟡 Вове
**Критерий:** оплата Stripe Paid есть, И выполняется хотя бы одно:
- Не в канале (при оплате — канал обязателен)
- Не в списке Вовы (Salebot)

**Действие:** Вова проверяет и добавляет в канал / список

---

### 🟠 Неполный доступ
**Критерий:** оплата + в канале + в списке Вовы + не в чате и/или не в практике  
**Действие:** пометить, может быть выбором человека

---

### ✅ Всё ОК
**Критерий:** оплата + канал + список Вовы + чат + практика  
**Действие:** —

---

### ❓ Непривязанные Stripe Paid (блок внизу)
**Критерий:** оплата Paid есть, email не удалось связать ни с кем из Telegram после всех 7 шагов матчинга  
**Действие:** Вова пробует идентифицировать по email

## Колонки таблицы

| Колонка | Описание |
|---------|----------|
| Имя | Из Telegram или Stripe |
| Username | TG ник |
| Email | Лучший найденный email |
| Список Вовы | ✅ / ❌ |
| Канал | ✅ / ❌ |
| Чат | ✅ / ❌ |
| Практика | ✅ / ❌ |
| Stripe | Сумма + дата последней оплаты |
| Новый/Вышел | Diff с предыдущим Сводом |
| Статус | Название группы (🔴 / 🟡 / 🟠 / ✅) |
| Действие | Конкретный текст для Тани / Вовы |

Diff (Новый/Вышел) считается по присутствию в Telegram относительно предыдущего Свода — независимо от группы.

---

## Action Items (автогенерируемый блок под таблицей)

- **Удалить из групп** — список всех из 🔴 (для подтверждения Таней перед удалением)
- **Вове: добавить в канал** — из 🟡, у кого нет канала
- **Вове: добавить в список Salebot** — из 🟡, кого нет в списке
- **Вове: идентифицировать** — ❓ непривязанные Stripe Paid, email списком
- **Обновить known_matches.json** — нечёткие матчи с ⚠️, требуют подтверждения Тани
- **Обновить tanya_agreements.json** — истекающие договорённости (`valid_until` ≤ +7 дней)
